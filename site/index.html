StackAnvil Maven

Fully patched builds for four Minecraft protocol projects. Each version comes from a StackAnvil release. PR test builds stay separate.

Add the repository

repositories {
    maven("https://stackanvil.github.io/maven/")
}

Group ID: io.github.stackanvil. Use the release version without the stack-v prefix.
